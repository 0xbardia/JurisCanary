## Reviewer audit

- **Reusable purpose:** each case is a frozen natural-language regression vector with a consensus-approved baseline and deterministic change classification. Governance, eligibility, compliance, and SLA applications can store its ID beside their own record.
- **Why GenLayer:** ordinary deterministic execution can compare bytes but cannot independently interpret natural-language criteria against evidence. Leader and Validators perform that interpretation; deterministic code handles state transitions.
- **Consensus location:** `_consensus_evaluation` calls `gl.vm.run_nondet_unsafe`; the Leader calls `_evaluate`, and the Validator validates the return type, independently calls `_evaluate` on the same frozen inputs, validates its result, and compares both decision fields.
- **Equivalence:** exact `overall_outcome` equality and exact ordered `criteria_results` equality. Reasoning, confidence, and prose are not requested, compared, or persisted.
- **State safety:** definition and baseline are assigned only during registration; rechecks append one record after accepted consensus and never rewrite prior records. Errors and disagreement return before mutation.
- **Failure behavior:** when validators disagree or fail, the contract prefers no new semantic result. The direct suite verifies rejection and unchanged state. Network rotation and network disagreement remain unverified.
- **Not a thin LLM wrapper:** the contract stores immutable test definitions, a baseline, latest accepted evaluations, deterministic drift statuses, bounded append-only history, and counters. Its Validator independently verifies substance.
